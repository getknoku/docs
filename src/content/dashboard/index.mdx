# Dashboard

The Knoku dashboard is where your team manages projects, sources, sessions, deployment surfaces, analytics, and workspace access.

## Project areas

| Area | Use it for | More |
| --- | --- | --- |
| Documents | Search indexed pages, inspect source groups, deactivate content | [Source groups](/sources/source-groups) |
| Sources | Add crawls, repo sync, uploads; monitor connected sources | [Sources](/sources) |
| Sessions | Read sessions from widget, bots, API, and deflector | [Sessions](/dashboard/sessions) |
| Widgets | Configure launcher copy, colors, behavior, and embed snippets | [Widget builder](/widget/widget-builder) |
| Channels | Connect Slack, Discord, and the support form deflector | [Deploy Knoku](/integrations) |
| Analytics | Track traffic, deflection, questions, and citations | [Analytics](/analytics) |
| API keys | Create and rotate Public API keys | [Public API](/integrations/public-api) |

## Workspace settings

Workspace settings apply across all projects in the organization: members, roles, billing, trial, SSO, audit log, and weekly digest.

See [Workspace & billing](/dashboard/workspace).

## Recommended setup order

1. Add an allowed domain.
2. Connect sources and confirm their source groups.
3. Install the widget or connect a channel.
4. Review sessions after first traffic.
5. Use analytics to fix gaps and improve high-traffic pages.
