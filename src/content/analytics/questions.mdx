# Questions

Questions groups real user asks into themes, so you can see what is missing, what is popular, and what should be clarified.

Open **Project > Analytics > Questions**.

## Views

| View | Shows | Use it to |
| --- | --- | --- |
| Gaps | Needs-support and weak-answer themes | Decide what to document next |
| Frequent | Popular themes across all questions | Improve important pages |
| All | Both groups together | Scan the full question landscape |

Legacy URLs for coverage gaps and top questions redirect here with the matching filter.

## Cluster fields

Each cluster includes:

- Theme label
- Summary of what users asked
- Suggested documentation improvement for gaps
- Sample questions
- Member count

Open a cluster to read the sample questions before editing docs. The exact wording often reveals whether the user missed an existing page, used different terminology, or asked for something not documented.

## How to use it

1. Select a period with enough volume.
2. Start with Gaps and fix the highest-count missing topics.
3. Check Frequent questions to improve pages users rely on often.
4. Open the linked conversations when a cluster is ambiguous.
5. After publishing changes, watch the same cluster over the next period.

## Gaps vs frequent

| | Gaps | Frequent |
| --- | --- | --- |
| Source turns | Needs-support or weak-answer turns | All questions |
| Main question | What is missing? | What is important? |
| Best action | Add or repair docs | Clarify, restructure, or improve discovery |

## Plan availability

Question clustering is available on all plans.
