# Discord

Connect Discord so community members can mention Knoku and get cited answers in a server thread. Discord is a public/community surface and uses the Public source group.

Use Discord for open-source communities, developer support servers, and public product communities.

## Install

1. Open **Project -> Channels -> Discord**.
2. Click **Add to Discord**.
3. Complete the Discord OAuth flow for the target server.
4. Confirm the bot can read messages, create threads, and send replies in the channels you want.

## Ask a question

Mention the bot in an allowed channel:

```txt
@Knoku how do I install the widget?
```

Knoku opens or replies in a thread and includes source links when available.

## Channel filter

Use channel IDs to limit where the bot listens. Leave the filter empty to allow every channel the bot can access.

## Curated ingest

Discord can also contribute source documents. Enable curated ingest and choose the marker reaction. When an approved thread is marked, Knoku can import that thread as searchable community knowledge.

Use this for answered community questions that should not disappear in chat history.

## Sessions and feedback

Discord threads map to [Sessions](/dashboard/sessions). Reactions and feedback are recorded for analytics where available.

## Remove Discord

Disconnect the installation from **Project -> Channels -> Discord**. You can also remove the app from Discord's server settings.

## Plan

Discord requires Open Source or above.
