# Deploy Knoku

Deploy Knoku where people already ask questions: on your website, inside support flows, in community channels, and in developer tools.

Every surface uses the same project index. The important difference is audience: public visitors should only reach Public content, while trusted team and backend surfaces can reach Internal content when configured.

Add repo sync, crawls, uploads, and workspace connectors from [Sources](/sources).

## Corpus access

Surface access is controlled by [source groups](/sources/source-groups):

| Surface | Corpus |
| --- | --- |
| Website widget | Public |
| Support form deflector | Public |
| MCP | Public |
| Discord | Public |
| Slack | Public + Internal |
| Public API key with public scope | Public |
| Public API key with internal scope | Public + Internal |
| Zendesk agent tooling | Public + Internal, Enterprise-gated |

Do not rely on frontend attributes to hide or expose knowledge. Put the document in the correct source group.

## Sessions and analytics
